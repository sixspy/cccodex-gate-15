# 闸口事件湖仓台

码头闸口扫描先落在贴源层，原文照收。建层员选定业务日，按事件字典把扫描收成明细层：进闸、出闸、倒箱。字典里没有的事件码、箱号不合法或时间读不出的扫描留在剔除清单，不进明细。

这里不管堆存量，只处理扫描事件怎么分层。

## 技术栈

| 层 | 选型 |
|----|------|
| 接口 | Python Flask |
| 页面 | React，无组件库 |
| 数据库 | PostgreSQL 16 |
